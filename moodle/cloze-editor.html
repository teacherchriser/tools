Editor de preguntas Cloze para Moodle

Creado por: Profesor Christian Serrano

Escribe la oración, marca los espacios con asteriscos y descarga el archivo XML para importarlo en Moodle.

Cómo escribir una pregunta
  • Encierra cada respuesta entre asteriscos: *Did* she *win* (win) the game?
  • Para aceptar varias respuestas correctas en un mismo espacio, sepáralas con /: Please take *photographs/photos*.
  • El texto fuera de los asteriscos (como la pista (win)) se muestra tal cual al estudiante.
  • Para importar: en Moodle, Banco de preguntas > Importar > formato Formato XML de Moodle.
